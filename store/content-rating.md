# Content rating questionnaire (draft)

Use this for the IARC form in Play Console (the questionnaire is the same set of topics in every console language). It matches version 0.9.1. The rating badge itself is assigned by IARC after you submit; do not invent a PEGI or ESRB number in the store listing.

## Violence

| Question | Answer |
| --- | --- |
| Does the app contain violence? | Yes |
| Style | Cartoon / fantasy. Low-poly soldiers, gates, and castles. No blood, no gore, no realistic weapons, no injury detail. |
| Target of violence | Fantasy characters and buildings. The player shoots a crowd into enemy crowds and castle walls. |
| Player can kill humans or realistic animals? | No |

## Fear, sex, language, substances, gambling

| Topic | Answer |
| --- | --- |
| Horror or jump scares | No |
| Sexual content or nudity | No |
| Profanity or crude humor | No. Interface copy is plain Turkish and the listing is Turkish and English. |
| Controlled substances, tobacco, alcohol | No |
| Gambling, loot boxes, or real-money contests | No. No purchases. Stars and coins are local and have no cash value. |
| Can the player lose real money or items bought with money? | No |

## User interaction and sharing

| Question | Answer |
| --- | --- |
| Users can interact or exchange information? | Yes. The daily leaderboard shows nicknames and shot counts to anyone who opens that day's board. |
| Users can share their location with others? | No |
| Users can purchase digital goods? | No |
| Unrestricted internet access? | Yes. Internet is used for the daily board. |

## Ads and children

| Question | Answer |
| --- | --- |
| Does the app contain advertising? | No for this build. No ad SDK is compiled in. Reward buttons do not display an ad. If you add AdMob later, change this answer before that release. |
| Made for kids / Designed for Families? | No. Public nicknames make Families enrollment the wrong choice. |

## Expected outcome

Cartoon fantasy violence with public nicknames and no sexual content, gambling, or real purchases. IARC will typically land in a low or early-teen band depending on how it weighs user interaction. Record the official result in Play Console; do not type a guessed age on the store listing yourself.
